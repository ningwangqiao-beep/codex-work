协议解释：以完成原 bar 交易后的收盘权益判断阈值。BUST 沿用原收盘清仓；DOUBLED 若仍持仓则调用同一 close() 按收盘清仓并计 0.07% 卖出费，阈值按清仓前权益判定，结算权益按清仓后现金。结算下一根开盘新账户注入 $10,000。末周期 OPEN_AT_END 沿用原窗口末市值计价，无强制卖出、无假定退出费。负结算值保留为负回收，不设置零下限。最低权益沿用基线收盘统计口径，含实际结算手续费。

拼接账户：stitched_equity = 已结算周期回收累计 + 当前周期收盘权益；total_injected 为截至该点全部外部注入；cumulative_net_pnl = stitched_equity − total_injected。已结算资金留作累计回收，不参与下一周期交易。逐日文件共 184 行，最后一日为部分日；单周期时长以开盘至结算收盘边界计，包含最后一分钟。

代码：run_phase2.py 从原模拟器函数保留全部买卖语句，仅加周期结算 hook 与提前返回、周期末记录；每次启动用 git 对象校验 backtest.py 原文。verify_phase2.py 对全部三变体 35 个周期逐一以未修改的基线模拟器重放，8,485 笔原成交逐字段完全一致；独立逐 fill 现金/持仓/手续费账本、周期结算、篮盈亏、日度外部资金流对账通过。网格内 V2 与第一部分逐字段相等。

复现：`python dbm/run_phase2.py`，随后 `python dbm/verify_phase2.py`。Python 3 标准库；联网只在数据门禁取 5–8 月归档及 CHECKSUM，缓存于 work/。
